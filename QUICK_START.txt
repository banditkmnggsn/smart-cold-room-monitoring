                         CLASS QUICK GUIDE
================================================================================

CLASS 0: NORMAL OPERATION ✅
──────────────────────────────────────────────────────────────────────────────
Meaning:        Cold room working perfectly
Temp Range:     6-8°C (stable)
Key Indicator:  diffT < 0.5°C (sensors agree)
Action:         Continue monitoring

CLASS 1: COOLING FAILURE ⚠️
──────────────────────────────────────────────────────────────────────────────
Meaning:        Cooling system failing, temp rising!
Temp Range:     > 9-10°C and RISING
Key Indicator:  dT > +0.2°C (consistent rise)
Action:         ALERT! Check compressor, door

CLASS 2: SENSOR FAULT 🔴
──────────────────────────────────────────────────────────────────────────────
Meaning:        Sensor hardware malfunction
Key Indicators:
  - diffT > 3.5°C (sensors disagree)
  - T < -15°C or T > 50°C (impossible temps)
  - stuck_count > 1000 (sensor frozen)
Action:         Replace DHT11 sensor immediately
