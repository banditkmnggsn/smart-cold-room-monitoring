   │  • avgT1_5 = average of last 5 T1 readings                │
   │  • avgT2_5 = average of last 5 T2 readings                │
   │                                                             │
   │ VARIANCE FEATURES (detect instability/noise)               │
   │  • stdT1_5 = std dev of last 5 T1 readings                │
   │  • stdT2_5 = std dev of last 5 T2 readings                │
   │                                                             │
   │ SENSOR HEALTH FEATURES                                     │
   │  • stuck_count1 = # of readings where dT1 < 0.1°C         │
   │  • stuck_count2 = # of readings where dT2 < 0.1°C         │
   │  • diffT = abs(T1 - T2) [MOST IMPORTANT!]                │
   └────────────────────────────────────────────────────────────┘
